# MK Studio — Frontend-Only Scope

The current release implements the supplied fashion-rental system as a presentation and interaction prototype. It provides static catalogue cards, product-detail rental controls, an in-browser multi-item rental order, checkout and payment-proof interface previews, a confirmation experience, order-tracking screens, and a backstage management preview.

All information is illustrative and retained only in the visitor's current browser session. The interface does **not** authenticate users, query a database, reserve dates, process payments, upload files, retain contact details, save product changes, or access real orders. These behaviours belong to the future backend and database phase.
